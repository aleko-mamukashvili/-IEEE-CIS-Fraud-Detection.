# IEEE-CIS Fraud Detection – თაღლითობის აღმოჩენის სისტემა
---
## პროექტის მიმოხილვა
პროექტი ეხება Kaggle-ის IEEE-CIS Fraud Detection შეჯიბრს, სადაც მიზანია ტრანზაქციების მონაცემების საფუძველზე თაღლითური ქმედებების იდენტიფიცირება. მონაცემები ხასიათდება მაღალი დისბალანსით, დიდი რაოდენობით გამოტოვებული მნიშვნელობებით და რთული იერარქიული სტრუქტურით. მოდელის შეფასების მთავარი მეტრიკაა ROC AUC Score.
---
## ჩემი მიდგომა პრობლემის გადასაჭრელად
ჩემი სტრატეგია დაეფუძნა ავტომატიზებულ Pipeline-ებს. შევქმენი Scikit-learn-ის სტანდარტის შესაბამისი პრეპროცესინგის კლასები, რაც საშუალებას იძლევა ნედლი მონაცემების დამუშავება, ახალი ცვლადების გენერაცია და მოდელის წვრთნა მოხდეს ერთიან სისტემაში.
---
## რეპოზიტორიის სტრუქტურა
რეპოზიტორია მოიცავს შემდეგ ფაილებს:

exploratory-analysis-and-baseline.ipynb – მონაცემების პირველადი კვლევა (EDA) და საბაზისო მოდელის შექმნა.

model-experiment-logisticregression.ipynb – წრფივი მოდელის ტესტირება და რეგულარიზაციის ექსპერიმენტები.

model-experiment-decision-tree.ipynb – გადაწყვეტილების ხეების წვრთნა და ჰიპერპარამეტრების ოპტიმიზაცია.

model-experiment-random-forest.ipynb – ანსამბლური მოდელის (Bagging) ტესტირება.

model-experiment-xgboost1.ipynb – გრადიენტული ბუსტინგის (XGBoost) ექსპერიმენტები და Feature Importance-ის ანალიზი.

model-inference1.ipynb – საუკეთესო მოდელის გამოყენება ტესტ სეტზე და Submission-ის მომზადება.

my-preprocessing-classes.ipynb – პრეპროცესინგისთვის საჭირო ყველა Custom კლასის განსაზღვრება.

README.md – პროექტის დეტალური დოკუმენტაცია.
