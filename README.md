# პროექტის მიმოხილვა

პროექტი ეხება Kaggle-ის IEEE-CIS Fraud Detection შეჯიბრს, სადაც მიზანია ტრანზაქციების მონაცემების საფუძველზე თაღლითური ქმედებების იდენტიფიცირება. მონაცემები ხასიათდება მაღალი დისბალანსით, დიდი რაოდენობით გამოტოვებული მნიშვნელობებით და რთული იერარქიული სტრუქტურით. მოდელის შეფასების მთავარი მეტრიკაა ROC AUC Score.

---

# ჩემი მიდგომა პრობლემის გადასაჭრელად

ჩემი სტრატეგია დაეფუძნა ავტომატიზებულ Pipeline-ებს. შევქმენი Scikit-learn-ის სტანდარტის შესაბამისი პრეპროცესინგის კლასები, რაც საშუალებას იძლევა ნედლი მონაცემების დამუშავება, ახალი ცვლადების გენერაცია და მოდელის წვრთნა მოხდეს ერთიან სისტემაში.

# სტრატეგიული ხედვა და მონაცემთა დამუშავება
შენმა მიდგომამ დაამტკიცა, რომ Feature Engineering უფრო მნიშვნელოვანია, ვიდრე უბრალოდ "ძლიერი" ალგორითმი.

მეხსიერების მართვა: reduce_mem_usage ფუნქციის გამოყენებით მოახდინე მონაცემთა ტიპების ოპტიმიზაცია, რამაც მოგცა საშუალება ემუშავა დიდ მასივებზე RAM-ის გადატვირთვის გარეშე.

NaN-ების მართვა (Drop & Impute): შენ სწორად განსაზღვრე, რომ სვეტები 90%-ზე მეტი გამოტოვებული მნიშვნელობებით (მაგ. Identity სვეტები) მოდელს აბნევს (Overfitting). ამიტომ შექმენი DropMissingFeatures კლასი, ხოლო დარჩენილი მნიშვნელობებისთვის გამოიყენე მედიანური შევსება.

# Feature Engineering
აქ ჩანს პროექტის ყველაზე ძლიერი მხარე — მონაცემების შინაარსობრივი გააზრება:

დროის ფაქტორი (hour, day): შენ დაინახე, რომ თაღლითობა ღამის საათებში უფრო აქტიურია. TransactionDT-დან საათის ამოღებამ მოდელს მისცა "ეჭვის საფუძველი" არააქტიურ დროს დაფიქსირებულ ტრანზაქციებზე.

Aggregation Features: გამოიყენე ჯგუფური სტატისტიკა (Amt_to_mean_card1), რათა მოდელს ეპოვა ანომალიები. მაგალითად, თუ ბარათის საშუალო ხარჯი $50-ია და უცებ ფიქსირდება $5000, მოდელი ამას მომენტალურად აღიქვამს, როგორც პოტენციურ Fraud-ს.

კორელაციების გაცხრილვა: CorrelationSelection კლასის მეშვეობით შენ მოაშორე "ხმაური" (V-features), სადაც კორელაცია > 0.9 იყო. ამით მოდელი უფრო სწრაფი და ზუსტი გახდა.

# მოდელების ექსპერიმენტები და ვალიდაცია
პროექტის ფარგლებში ჩატარდა ექსპერიმენტების სერია, სადაც თითოეული მოდელი მოწმდებოდა $ROC\ AUC$ მეტრიკით:
Logistic Regression (Baseline): დააფიქსირა დაბალი სიზუსტე (0.865), რაც გახდა სიგნალი, რომ საჭირო იყო უფრო რთული, არახაზოვანი მოდელები.

Decision Tree (გადაწყვეტილების ხეები)მოდელმა გაიარა ევოლუციის რამდენიმე ეტაპი:Initial Run: $AUC = 0.8411.Overfitting Run: სიღრმის გაზრდამ  გამოიწვია მკვეთრი დისბალანსი (Train: 0.9554, Val: 0.7939).Golden Middle: პარამეტრების ოპტიმიზაციით  მიღწეულ იქნა სტაბილური ბალანსი.

Random Forest (შემთხვევითი ტყე)Base RF: კლასების დისბალანსის დასაბალანსებლად გამოყენებულია class_weight='balanced'. ვალიდაციის AUC: 0.8808.Super Advanced RF: 300 ხისგან შემდგარი ანსამბლი გაფართოებული ფიჩერებით. ვალიდაციის AUC გაიზარდა 0.8951-მდე.

XGBoost (გრადიენტული ბუსტინგი)პროექტის ფინალური მოდელი, რომელიც საუკეთესოდ უმკლავდება Tabular მონაცემებს და არახაზოვან კავშირებს.
